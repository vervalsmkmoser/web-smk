PANDUAN SETUP PORTAL ADMIN SMK MOCH SROEDJI JEMBER
Hosting: GitHub Pages | Database, autentikasi, dan foto: Supabase

FITUR
- admin.html: login admin melalui Supabase Auth
- tambah, edit, hapus berita dan pengumuman
- unggah foto berita dan logo melalui Supabase Storage
- ubah informasi sekolah, program keahlian, kontak, beranda, profil, visi, dan misi
- index.html mengambil berita terbit dan informasi dari Supabase

LANGKAH 1 — BUAT PROYEK SUPABASE
1. Buka https://supabase.com/ dan masuk/buat akun.
2. Buat project baru dan simpan password database di tempat aman.
3. Buka Project Settings > API. Salin Project URL dan anon/public key.
4. Jangan pernah memakai service_role key di index.html atau admin.html.

LANGKAH 2 — BUAT TABEL, POLICIES, DAN STORAGE
5. Di Supabase, buka SQL Editor > New query.
6. Buka file supabase_setup.sql dari paket ini, salin seluruh SQL, lalu jalankan (Run).
7. SQL membuat tabel news, site_settings, admin_users, mengatur Row Level Security (RLS), dan bucket school-media.

LANGKAH 3 — BUAT AKUN ADMIN
8. Buka Authentication > Users > Add user, masukkan email admin dan kata sandi kuat.
9. Salin UID akun admin dari daftar Users.
10. Buka SQL Editor dan jalankan perintah ini, ganti UID dengan UID akun admin:
    insert into public.admin_users (user_id) values ('GANTI_DENGAN_UID_USER_ADMIN');
11. Jangan aktifkan pendaftaran publik jika hanya pengelola sekolah yang boleh mengakses portal. Akun admin harus dibuat manual.

LANGKAH 4 — MASUKKAN KONFIGURASI SUPABASE
12. Buka index.html dan admin.html.
13. Cari:
    const SUPABASE_URL = "ISI_SUPABASE_PROJECT_URL";
    const SUPABASE_ANON_KEY = "ISI_SUPABASE_ANON_KEY";
14. Ganti dua nilai itu dengan Project URL dan anon/public key dari Supabase Dashboard.
15. Simpan kedua file.

LANGKAH 5 — PUBLIKASIKAN DI GITHUB PAGES
16. Unggah index.html, admin.html, dan file panduan (opsional) ke root repository GitHub.
17. Pastikan Settings > Pages diatur ke Deploy from a branch, branch main, folder /(root).
18. Tunggu website terbit.
19. Halaman publik: https://USERNAME.github.io/NAMA-REPOSITORY/
20. Portal admin: https://USERNAME.github.io/NAMA-REPOSITORY/admin.html
21. Login dengan email dan password admin yang dibuat di Supabase.
22. Tambah berita/pengumuman dengan status Terbit. Periksa halaman publik.

KEAMANAN
- RLS harus aktif. Jangan menghapus policies keamanan dari SQL.
- Hanya UID yang terdaftar pada public.admin_users dapat mengubah konten.
- Anon/public key memang digunakan pada frontend, tetapi aksesnya dibatasi oleh RLS.
- Jangan bagikan password admin. Jika kata sandi bocor, ganti dari Supabase Authentication.
- Bucket school-media bersifat publik agar foto dapat ditampilkan di website; hanya admin terdaftar yang boleh upload, update, dan menghapus.
- Foto dibatasi maksimal 5 MB dan tipe gambar umum.

CATATAN
- Portal membutuhkan konfigurasi Supabase asli agar bisa digunakan; paket tidak membuat proyek atau akun Supabase secara otomatis.
- Pengaturan yang tersimpan di database hanya memperbarui elemen yang telah dihubungkan pada halaman publik. Beberapa bagian lain masih berupa teks statis.
- Form PPDB/kontak yang ada di versi awal belum menyimpan pendaftar ke database.


FILE JAVASCRIPT TERPISAH
- app.js: fungsi halaman publik, memuat berita/pengumuman dari Supabase, formulir kontak dan PPDB.
- admin.js: login admin, pengelolaan berita/pengumuman, unggah foto, dan pengaturan informasi sekolah.
- supabase-config.js: satu tempat untuk mengisi Project URL dan anon/public key Supabase.
Jangan menaruh service_role key di website. Terapkan RLS/policies dari supabase_setup.sql.

PENTING
Paket ini adalah kode website lengkap yang siap dipasang, bukan website yang sudah online atau sudah tersambung ke proyek Supabase milik Anda. Agar benar-benar aktif, isi supabase-config.js dengan kredensial proyek Supabase Anda, jalankan supabase_setup.sql, buat akun admin melalui Supabase Authentication, lalu masukkan UID akun tersebut ke tabel public.admin_users. Setelah itu unggah seluruh isi folder ke repositori GitHub dan aktifkan GitHub Pages.

DESAIN
File style.css menerapkan gaya minimalis: latar putih/abu terang, aksen biru tua, tipografi sederhana, kartu bersih, dan bayangan yang dikurangi.
